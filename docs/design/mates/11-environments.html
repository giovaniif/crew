11Environments = machine + accounts

One concept replaces servers and environments. An environment answers two questions: where does the mate run (This Mac, or a server that you connected over SSH) and whose accounts does it use (Your accounts on that machine, or a separate identity that lives on that machine). The list groups environments by machine. A machine row shows its connection state; select it to see the connection and the logins that crew found there. Under each machine: Your accounts (always there, read-only facts plus extra secret variables) and its separate identities (the old Custom). + Machine connects a server; the first-run SSH setup uses the same flow. Settings › Servers goes away. The words "Local" and "Custom" go away. A separate identity can be copied to another machine (11g, 11h): the git name, tokens and variables copy; the target machine makes its own SSH key, which you add on GitHub. The phone pairs with each machine. This Mac is hidden from the list when no mates run on it.
