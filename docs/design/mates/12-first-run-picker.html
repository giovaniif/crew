12First run, picker and copy

First run is three full-window steps (no sidebar until the first run ends or is skipped): where (This Mac or a server over SSH), ready (the machine becomes the environment "devbox · your accounts" and shows the logins found there), then make the first mate with that environment already picked. On a server, crew does not offer "This Mac" as a choice. New mate picks from all machines (12d). A mate is fixed to its machine: the rail picker on the mate page offers only environments on the same machine (12e). To use a mate on another machine, copy it from the ⋯ menu (12g): a new mate with the same role, memory and look; the original stays.

12fModel and decisions

The model

Machine

This Mac, or a server over SSH. Each machine runs its own crew (daemon). It has a connection state and the logins that crew found there.

Identity

Your accounts: one per machine, always there, read-only, plus extra secret variables. Separate identity: own git name, SSH key, tokens and harness accounts. It lives on one machine. A copy to another machine copies the name and tokens; that machine makes its own SSH key.

Environment

= machine + identity. Its name is "machine · identity", for example "devbox · work-bot". A mate has exactly one.

Mate

Belongs to the crew on its machine. Its threads, memory and worktrees are there. A mate never moves. "Copy to another machine…" makes a new mate there with the same role, memory and look; the original stays.

The "This computer ▾" switcher goes away (decided)

The app connects to every machine at the same time and shows one merged list. Mates, Sessions and Approvals show all machines; a small machine tag ("devbox") is on each row only when there are two or more machines. The sidebar foot shows "2 machines connected" and opens Environments. A machine that is not reachable shows its mates greyed, with the reason.

The phone pairs with each machine. This Mac is hidden when no mates run on it.
