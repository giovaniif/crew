Sessions moves to second place: a compact table of local harness sessions (state, harness, repo@branch, PR, last activity), with sessions that mates started in their own group. A row opens the session view of frames 1a and 2a. First run is two short steps: name and role in a composer, then pick an environment (Local is the default; a new Custom one opens the editor of 9a after create). A link offers a plain session instead. Settings is fixed: the nav is full height and does not scroll, only the content scrolls, rows are compact, and each notification is one row: label at left, the banner switch and the sound Select at right.
