9Environments

An Environment is a named profile that mates use. Local (this Mac) is always first and is read-only: it shows what crew found. Custom is isolated and has sections: git identity, the SSH key that crew made (public key, Copy, and where to add it on GitHub), GitHub token, one account per harness, and extra secret variables. Secrets are write-only: a row shows set or not set and offers Set / Replace / Remove, never the value. The header shows the mates that use the environment. A change shows a notice that it applies at the next conversation. The kind (Local or Custom) is chosen only at creation; the editor has no kind switch. New key… makes a new SSH key but keeps the old one active until you confirm that you added the new one to GitHub (9d).
